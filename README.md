# Orbit Lab Documentation

This repository contains the official engineering documentation for Orbit Lab.

The documentation is written in Markdown and published using Material for
MkDocs.

## Local development

Create and activate a Python virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```
